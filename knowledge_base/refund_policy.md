# Refund Policy

## Refund Eligibility

A refund can be considered when:

- The payment has been successfully captured.
- The order is eligible for cancellation or refund.
- The refund request has passed the required verification process.

## Failed Transactions

- A failed transaction is not automatically considered an approved refund.
- The payment status must first be verified.
- If the transaction status is unclear, escalate it to the payment support team.

## Refund Processing

- Refunds require transaction verification and approval.
- The support agent must not guarantee a refund before approval.
- Refund timelines must only be communicated when confirmed through an authorized transaction record.
- Do not invent processing timelines.

## Required Information

Agents may request:

- Transaction reference number.
- Order ID.
- Transaction date.
- Transaction amount.

Never request passwords, OTPs, CVV or full card numbers.
