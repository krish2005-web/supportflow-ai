# Account Access Support Policy

## Password Reset

- Customers can request a password reset through the Forgot Password option.
- Password reset links are valid for 30 minutes.
- Requesting a new reset link invalidates the previous link.
- Customers should check their spam or junk folder if the email is not received.

## Password Reset Troubleshooting

If a password reset link is not working:

1. Check whether the link has expired.
2. Request a new password reset link.
3. Open the newest link.
4. Try opening the link in a private or incognito browser window.
5. If the issue continues, escalate the ticket to the technical support team.

## Account Security

- Support agents must never ask customers for their passwords.
- Agents must never request OTPs.
- Agents must not change account credentials without following the account verification process.
